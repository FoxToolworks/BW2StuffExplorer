# STUFF Explorer V0.4 — authoritative specification

This document is the acceptance baseline for V0.4. Test builds may be corrected until every applicable item is satisfied; the specification is not invalidated by an implementation error.

## Scope and safety

- Windows desktop explorer for Black & White 2 `.stuff` archives.
- The proven V0.3 WPF application and archive logic remain the technical base.
- Source archives are read-only and are never modified.
- Exported files preserve their original virtual directory structure.
- No import, writer, repacker, DDS preview, remaster or Photoshop automation in V0.4.
- The visible interface is English; strings remain internally localizable.

## Opening archives

- `File > Open Archive…`, `Ctrl+O`, and drag-and-drop of one `.stuff` file.
- Invalid, damaged or unsupported files produce an understandable error instead of a crash.

## Main window and presentation

- Menu, compact navigation bar, resizable folder tree, file view and status bar.
- Windows 11 Explorer-inspired light presentation: white work area, cool light gray chrome and subtle Explorer-blue focus/selection.
- Compact desktop spacing without large action surfaces, shadows or heavy cards.

## Menus and shortcuts

- Main menus: `File · Edit · View · Tools · Help`.
- Open, export, copy path/name, sorting, grouping, properties and About actions.
- `Ctrl+O` opens, `Ctrl+F` focuses search, `Ctrl+E` exports the selection, `F5` refreshes, and `Esc` clears search or closes Properties.

## Navigation bar

- Back, Forward, Up and Refresh are one compact icon group with approximately 32 px targets.
- Disabled actions remain visible but faded; hover uses a subtle gray surface.
- The breadcrumb exposes clickable path segments and keeps the current level visible.
- Search uses the current folder in its hint, shows a magnifying glass while empty, and changes to `X` when text is present.

## Folder tree

- The archive root uses a small neutral gray archive-box icon.
- Folders use compact yellow Explorer-like icons.
- Slim chevrons point right when closed and down when expanded.
- Hover is light gray; the active folder uses a softly rounded light-blue selection.
- Expanded but inactive folders remain neutral; the tree width stays resizable.

## File and folder view

- Normal browsing shows only the selected folder's direct files.
- Columns: `Name · Modified · Type · Size · Offset`; `Path` appears only during search.
- Name consumes flexible space while technical columns keep sensible widths.
- Headers remain white with a fine lower edge and a small active-sort arrow.
- Rows are compact, support multiple selection and use subtle gray hover and light-blue selection.
- Date, time and numbers follow the current Windows regional settings; unavailable archive metadata is never invented.

## File visuals

- Folders use yellow Explorer-like icons.
- DDS files may use a subtle image/texture symbol.
- Unresearched formats use a neutral file sheet with small color accents.
- Full BW2 file-type icon classification is deferred to V0.5.

## Search

- Search is recursive within the selected folder branch.
- Results from subfolders are combined and expose their origin in the `Path` column.
- `X` or `Esc` clears search and restores the normal direct-folder view.
- Search state and the current result count are reflected in the status bar.

## Sorting and grouping

- Sort by Name, Type, Size or Offset in ascending or descending direction.
- Group by None or Type.
- Default: Name ascending and grouped by Type.
- Group headings are transparent, without a gray strip or divider, and use the same slim chevrons as the tree.

## Context actions and export

- File selections expose Export, Properties, Copy Full Path and Copy File Name.
- A folder export is recursive and preserves the original subfolder structure.
- Single files, multiple files and folders are supported.
- Existing destination files are never overwritten silently.
- Progress and completion are visible; an individual failure is reported safely.
- The `.stuff` source remains unchanged.

## Status bar

- White background with a fine gray upper edge.
- Status on the left and displayed object count on the right.
- Representative states: Ready, Searching, Exporting and Export complete.

## Properties window

- 32 px file visual, complete filename and smaller gray type label in the header.
- Compact two-column property layout without a visible table grid or editable controls.
- Long values wrap; path, offset, size and technical values can be selected and copied.
- Resizable with a sensible minimum size; mainly the value column grows.
- Close button, window `X` and `Esc` close the window.
- Bounds are remembered only for the current application session.

## Application icon

- Detailed freestanding STUFF archive chest with a magnifying glass and subtle Black & White 2 asset imagery.
- Transparent background with a strong silhouette that remains recognizable at small sizes.
- Dedicated images from 16 through 256 px, used by the window, taskbar and executable.

## Explicitly deferred

- Editing or overwriting archives.
- Import, writer or repacker functionality.
- DDS preview or image editing.
- Remaster and Photoshop automation.
- Complete proprietary file-format research and specialized icons for every type.
- Visible language selection.
