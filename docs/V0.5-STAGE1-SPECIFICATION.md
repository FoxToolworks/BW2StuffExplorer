# Version 0.5 Stage 1 — Classification Foundation

## Scope

Stage 1 adds a read-only, extension-based Black & White 2 asset classification layer. It does not inspect file payloads yet. Content-aware BWM subtypes, DDS roles and technical metadata are intentionally deferred to later stages.

Each archive entry receives three separate values:

- **Format** — the normalized filename extension, such as `DDS` or `BWM`;
- **Asset category** — a broad family used for optional grouping;
- **File type** — the most specific description confirmed at the current analysis stage.

## Known formats

| Format | File type in Stage 1 | Asset category |
| --- | --- | --- |
| DDS | Texture (DDS) | Textures & Images |
| TGA | Targa Image (TGA) | Textures & Images |
| BMP | Bitmap Image (BMP) | Textures & Images |
| 555 | RGB555 Sky Texture (555) | Textures & Images |
| BWM | 3D Model (BWM) | 3D Models |
| BIK | Bink Video (BIK) | Video |
| CAM | Camera Path Data (CAM) | Camera Data |
| EXC | Camera Exclusion Zone (EXC) | Camera Data |
| CSK | Creature Model & Morph Data (CSK) | Creature Data |
| CHA | Creature Hair/Fur Data (CHA) | Creature Data |
| CCS | Creature Support Data (CCS) | Creature Data |
| ABN | Advisor Animation Bank (ABN) | Animation & Dialogue |
| DAN | Dialogue Annotation Data (DAN) | Animation & Dialogue |

Unknown extensions retain their uppercase format in `Unknown Data (FORMAT)`. Extensionless entries use `Unknown Data`. Both belong to the `Unknown Data` category.

## Explorer behavior

- The existing Type column displays the friendly file type and sorts by that display value.
- `Group by > File type` groups by the friendly file type and remains the default.
- `Group by > Asset category` groups by the broader asset family.
- `Group by > None` remains available.
- The General properties view displays the same friendly file type.
- Archive reading, searching and extraction remain unchanged and read-only.

## Deferred refinements

- BWM payload inspection will refine `3D Model (BWM)` into static, skinned or unknown model data.
- BWM material relationships will refine generic DDS textures into confirmed diffuse, light, specular, growth, normal, animated or multiple-role textures.
- A separate File details tab will show factual technical metadata such as DDS dimensions, compression and mipmap count.
- Unprovable values remain `Unknown`. Modding recommendations will be kept separate from factual file metadata.
